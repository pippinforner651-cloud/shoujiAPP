# E23跑起来 · 安装指南（内测版）

## Android 安装方式

### APK 来源

当前最新 APK 构建自 GitHub Actions：
- 构建时间：2026-07-25
- 对应代码基线：`710174d`（E23 V2 路线目标冻结版）
- 后续文档更新（Phase 2.1C/D）未影响 APK 逻辑，可直接使用此版本

### 安装步骤

1. 从以下链接下载 APK 文件：
   **https://github.com/pippinforner651-cloud/shoujiAPP/actions/runs/30151006177**
   - 打开链接 → 页面底部 **Artifacts** → 下载 `E23跑起来_Phase1.5_GPS_Live_Fix.zip`
   - 解压 ZIP → 得到 `.apk` 文件

2. 将 APK 文件传输到手机（微信发送/数据线拷贝/网盘下载均可）

3. 手机上点击 APK 文件安装
   - 如提示「未知来源应用」：在设置中允许安装未知来源应用
   - 如提示「Google Play 保护机制」：点击「仍要安装」

4. 安装完成后打开 APP

### 权限说明

首次使用时会请求以下权限：

| 权限 | 用途 | 可选 |
|---|---|---|
| **精确定位** | GPS 记录跑步距离和轨迹 | 户外跑必需，室内跑不需要 |
| **通知** | 锁屏时显示跑步状态 | 可选，跑步时推荐开启 |
| **电池优化（忽略）** | 防止锁屏后 GPS 被系统暂停 | 推荐关闭电池优化 |

> 定位权限仅在开始户外跑时才请求。如果拒绝，仍可使用室内跑功能。

## iPhone 使用方式

### 通过 Safari 打开 PWA

当前 **PWA 公网地址尚未部署**，这是下一步任务。

临时方案：

1. 联系班级管理员获取当前开发预览地址
2. 在 iPhone Safari 浏览器中打开该地址
3. 点击底部中间的「分享」按钮
4. 向下滑动找到 **「添加到主屏幕」**
5. 点击右上角「添加」
6. 手机桌面上会出现 E23 跑起来图标，以后从这里打开

### iOS 注意事项

- iPhone 后台定位能力与 Android 有差异
- 锁屏后 GPS 可能不会持续记录
- iOS 完整适配正在规划中
