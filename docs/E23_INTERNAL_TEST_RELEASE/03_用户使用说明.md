# E23跑起来 · 用户使用说明（1页版）

## 第一步：打开入口

手机浏览器访问班级提供的链接。

> 建议使用 Android 手机体验（iOS版正在完善中）。

---

## 第二步：注册账号

进入后点击 **注册**。

填写：

- 邮箱
- 密码
- 昵称

点击注册，自动登录。

> 也可以用「测试登录」快速体验，但数据只保存在本机。

---

## 第三步：跑步

点击底部 **「跑步」** 进入跑步页。

### 户外跑

1. 选择 **「户外跑」**
2. 点击 **「开始户外跑」**
3. 等待手机获取GPS信号
4. GPS就绪后开始运动
5. 途中可暂停/继续
6. 结束后点击 **「结束保存」**

### 室内跑

1. 选择 **「室内跑」**
2. 点击 **「开始室内计时」**
3. 运动结束后填写跑步机距离
4. 保存

### 设置目标（可选）

跑步前可以设置目标：

- 跑多远（公里）
- 跑多久（时间）
- 消耗多少（千卡）

---

## 第四步：查看

### 我的公里

底部 **「我的」** 页面查看：

- 个人累计公里
- 每次跑步记录

### 班级累计

底部 **「地图」** 或 **「排行」** 查看：

- 班级总公里
- 中国路线当前进度
