# E23跑起来 · 内部体验发布包

## 定位

**E23内部体验版。**

这是E23班级自己的运动工具，不是正式商业APP。

## 内容说明

| 文件 | 说明 |
|---|---|
| `01_内测邀请文案.md` | 面向E23同学的微信群邀请文案 |
| `02_产品介绍.md` | 产品背景和玩法介绍 |
| `03_用户使用说明.md` | 1页快速上手指南 |
| `04_当前版本说明.md` | 版本状态和能力清单 |
| `05_已知问题说明.md` | 当前已知问题和优化计划 |
| `06_反馈收集模板.md` | 同学反馈收集表单 |

## 使用建议

1. 先在班群发 `01_内测邀请文案.md`
2. 感兴趣的同学可查看 `02_产品介绍.md` 了解详情
3. 准备体验的同学按照 `03_用户使用说明.md` 操作
4. 遇到问题可查阅 `05_已知问题说明.md`
5. 反馈请填写 `06_反馈收集模板.md`
