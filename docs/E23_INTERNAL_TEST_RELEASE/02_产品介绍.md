# E23跑起来 · 产品介绍

## 为什么做E23跑起来

E23班有一个共同目标——环绕中国边境线。

但一直以来，大家的运动数据分散在各个平台，没有统一汇总的方式。

E23跑起来就是为了解决这个问题：

**让每一公里的运动，都能被看到、被记录、成为班级共同前进的一部分。**

---

## 怎么玩

很简单：运动 → 记录 → 贡献公里 → 全班推进路线。

每个人做自己力所能及的运动：

- 户外跑步
- 室内跑步机
- 走路
- 任何有距离记录的运动

每次运动结束后，APP会记录你的公里数。

这些公里数会：

1. 计入 **你的个人累计**
2. 同时计入 **E23班级累计**
3. 推动全班路线前进

---

## 个人贡献

每个人都有自己独立的运动记录。

你可以看到：

- 自己总共跑了多少公里
- 每次运动的详细记录
- 自己的平均配速和时长

数据保存在云端，换手机也不丢失。

---

## 班级路线

全班同学的公里数会汇总到一起。

路线目标：**约27,000公里**——环绕中国边境线的总里程。

（注：此前有24,000km的参考路线，属于上一版历史数据。E23 V2正式目标为约27,000km。）

随着每个人的运动，班级路线会逐步推进，所有人能看到当前进度。
