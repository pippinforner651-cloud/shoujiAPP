## 安装步骤

1. 将 APK 文件传输到手机（微信发送 / 数据线 / 网盘均可）

2. 在手机上点击 APK 文件 → **继续安装**

3. 如提示「未知来源应用」：
   - **华为：** 设置 → 安全 → 更多安全设置 → 允许安装未知来源应用
   - **小米：** 设置 → 隐私保护 → 特殊权限设置 → 安装未知应用
   - **OPPO / vivo：** 安装时点击「仍要安装」
   - **其他品牌：** 安装时一般会弹出提示，允许即可

4. 安装完成后，桌面出现 **E23跑起来** 图标

## 权限说明

首次打开 APP，进入户外跑时会请求以下权限：

| 权限 | 用途 | 说明 |
|---|---|---|
| **精确定位** | GPS记录跑步轨迹和距离 | 户外跑必需。如果拒绝，只能使用室内跑功能 |
| **通知** | 锁屏时显示跑步状态 | 推荐允许。跑步时可在通知栏看到距离和时长 |
| **电池优化** | 防止系统在锁屏后关闭GPS | 如关闭电池优化，锁屏后GPS能持续记录 |

> 所有权限仅用于跑步功能。APP 不会在后台获取位置信息用于其他用途。

## 常见问题

**Q：安装时提示「解析包出现问题」？**
A：下载的 APK 文件可能不完整，请重新下载。

**Q：安装后打开闪退？**
A：请确认 Android 版本为 8.0 或以上。如仍闪退，请在班级群反馈并提供手机型号和 Android 版本。

**Q：需要 Google Play 服务吗？**
A：不需要。APP 使用 Android 原生定位接口，不依赖 Google 服务。

**Q：可以用微信扫码直接安装吗？**
A：微信扫码后会提示在浏览器中打开，选择「浏览器打开」即可下载。
