# E23跑起来 · 项目总览（Codex最终评审版）

## 项目定位

E23跑起来不是普通跑步APP。

**核心目标：** 北京大学汇丰商学院 EMBA E23 班全体同学，通过个人跑步运动贡献公里数，共同完成环绕中国边境线的路线挑战。

**核心链路：**
```
个人运动 → 贡献公里 → 云端汇总 → 班级共同推进路线 → 全员共享进度
```

**路线目标：** **~27,000 km**（E23 V2 正式冻结目标）
> 21423km 是 V1 历史基线，不作为当前正式目标。
> **换算规则（冻结）：真实跑量与路线推进 1:1**——用户真实跑 1km = 班级路线前进 1km（completed_km = SUM(distance_m)/1000.0）；禁止 1:10/虚拟放大。

**目标用户：** E23班约 50-80 名同学 + 老师
**技术形态：** PWA（主） + Android APK（原生GPS增强）
