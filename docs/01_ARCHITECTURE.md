## E23跑起来 · 技术架构

## 目标架构（Phase 2 之后）

```
┌─────────────┐  ┌─────────────┐  ┌─────────────┐
│ Android APK  │  │  PWA / Web  │  │  iOS App    │
│ (Capacitor)  │  │  (React)    │  │ (Capacitor) │
└──────┬───────┘  └──────┬──────┘  └──────┬──────┘
       │                 │                 │
       ├───────── Supabase Auth ───────────┤
       │                 │                 │
       └───────── Supabase API ────────────┘
                         │
              ┌──────────┴──────────┐
              │    PostgreSQL       │
              │  (Supabase 托管)     │
              │  + Row Level Sec    │
              └──────────┬──────────┘
                         │
              ┌──────────┴──────────┐
              │   Supabase Realtime │
              │   (WebSocket)       │
              └─────────────────────┘
```

## 架构原则

1. **Cloud Repository + Local Cache Repository 双模式**
2. **Row Level Security 实现权限，不在前端隐藏按钮**
3. **网络断开时本地优先，恢复后自动同步**
4. **LocationProvider 统一接口，各平台独立实现**
