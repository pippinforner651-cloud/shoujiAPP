## 7. user_stats 触发器（新增实现，非原始恢复）单独说明

| 项 | 值 |
|---|---|
| 新增函数 | `public.update_user_stats_fn()` |
| 新增触发器 | `trg_update_user_stats`（run_activities AFTER INSERT/UPDATE/DELETE） |
| 聚合口径 | status='valid'，按 user_id 全量 SUM(distance_m)/SUM(duration_s)/COUNT(*) + MAX(end_time)::date；无有效活动时写 0 |
| 与前端排行榜匹配 | CloudStatsRepo.getLeaderboard() 查 user_stats 按 total_distance_m 排序 — 字段名完全匹配 ✅ |
| 风险 | ① 原始 migration 无此触发器（新增行为，如需严格还原可跳过脚本第 3 节）；② last_activity_date 依赖 end_time（NULL 时为空，不影响统计）；③ 回算含"清理无有效活动用户的统计行"（派生数据清理，非业务数据） |

## 10. 回滚方案

```sql

DROP TRIGGER IF EXISTS trg_update_user_stats ON public.run_activities;
DROP FUNCTION IF EXISTS public.update_class_stats_fn();
DROP FUNCTION IF EXISTS public.update_user_stats_fn();
-- 可选：清空三张统计表（仅派生数据）
DELETE FROM public.user_stats; DELETE FROM public.class_stats; DELETE FROM public.route_progress;
```

> 回滚不影响 run_activities / classes / profiles 业务数据。
