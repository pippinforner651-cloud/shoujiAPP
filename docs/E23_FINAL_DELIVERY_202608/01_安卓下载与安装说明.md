# 01 · Android 下载与安装说明

## 1. 下载 APK

**最新版：** E23跑起来 V2 内部体验版 · Android

**下载地址（GitHub Release）：**
```
https://github.com/pippinforner651-cloud/shoujiAPP/releases/latest
```

> 内测期间如 Release 尚未就绪，可联系班级管理员获取 APK 文件（微信发送或网盘）。

## 2. 安装步骤

1. 下载 `.apk` 文件到手机
2. 点击 APK 文件 → **继续安装**
3. 如提示「未知来源应用」：
   - 华为：设置 → 安全 → 更多安全设置 → 允许安装未知应用
   - 小米：设置 → 应用设置 → 授权管理 → 安装未知应用
   - OPPO/vivo：安装时点击「仍要安装」
4. 安装完成后桌面出现 **E23跑起来** 图标

## 3. 权限说明

| 权限 | 用途 | 是否必需 |
|---|---|---|
| 精确定位 | 户外跑 GPS 轨迹与距离 | 户外跑必需 |
| 通知 | 锁屏跑步状态显示 | 推荐开启 |
| 电池优化（关闭） | 锁屏持续记录 | 推荐 |

> 拒绝定位权限仍可使用「室内跑」和「手动补录」。

## 4. 版本说明

- 版本名称：**E23跑起来 V2 内部体验版**
- 路线目标：**约 27,000 km**（真实跑量与路线推进 **1:1**：跑 1km = 班级路线前进 1km）
- 系统要求：Android 8.0+

## 5. 常见问题

- **安装提示解析包错误**：下载不完整，请重新下载。
- **无法定位**：确认系统定位开关已开、已授予精确定位权限；可在「我的 → GPS诊断」查看详细状态。
- **数据同步**：跑步记录保存在云端（登录状态下）与本机；换手机登录同账号可从云端恢复。
