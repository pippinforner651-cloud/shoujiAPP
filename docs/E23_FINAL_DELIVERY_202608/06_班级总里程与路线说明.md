# 06 · 班级总里程与路线说明

## 1. 班级挑战目标

**E23 班全体同学共同完成约 27,000 km 中国路线挑战。**

- 每个同学的运动公里数计入个人累计
- 全体同学之和计入班级累计
- 班级累计推动中国路线前进（地图页面可看进度）

> 说明：V1 历史路线 21,423 km 与路线包精确 27,171 km 均**不作为当前展示目标**；正式目标统一为 **约 27,000 km**。

## 2. 个人累计 vs 班级累计（必须区分）

| 字段 | 含义 | 数据来源 |
|---|---|---|
| 个人贡献公里 | 本人有效跑步之和 | 云端 run_activities（本人） |
| 路线推进公里 | 班级全体有效跑步之和 | 云端 class_stats / route_progress |

- 两个字段独立展示，不得混淆
- 班级数据以云端为准，不以本机 localStorage 为准

## 3. 数据源说明（当前阶段）

| 页面 | 云端数据源 | 当前状态 |
|---|---|---|
| 登录/注册 | Supabase Auth | ⚠️ 后端恢复后可用 |
| 个人资料 | profiles | ⚠️ 后端恢复后可用 |
| 个人跑步 | run_activities | ⚠️ 后端恢复后可用 |
| 班级总里程 | class_stats | ⚠️ 后端恢复后可用 |
| 路线进度 | route_progress | ⚠️ 后端恢复后可用 |
| 排行榜 | user_stats | ⚠️ 后端恢复后可用 |

> 当前 Supabase 后端不可达（可能已暂停），页面显示本机数据时界面标注「离线预览」，**不视为正式班级统计**。

## 4. 离线预览标识

- 本地开发/离线模式使用 localStorage + SQLite
- 界面明确标注「离线预览」/「1:1 真实跑量」
- 不得将离线数据显示为正式班级数据

## 5. 规则冻结

| 规则 | 说明 |
|---|---|
| 约 27,000 km | 正式路线目标，冻结 |
| 个人≠班级 | 两个字段独立展示，冻结 |
| 云端事实源 | 班级统计以 Supabase 为准，冻结 |
| 禁止假多人 | 不得生成虚假排行/进度/动态，冻结 |
