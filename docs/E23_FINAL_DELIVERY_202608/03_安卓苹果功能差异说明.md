# 03 · Android 与 iPhone 功能差异说明

> 差异主要由系统能力决定（GPS 后台限制等）。

| 功能 | Android | iPhone (PWA) |
|---|---|---|
| 安装方式 | APK 安装包 | Safari 打开 + 添加到主屏幕 |
| 账号注册/登录 | ✅ | ✅ |
| 户外跑 GPS 记录 | ✅ 前台 + 锁屏后台 | ✅ 仅页面前台；锁屏可能停止 |
| 室内跑计时 | ✅ | ✅ |
| 手动补录 | ✅ | ✅ |
| 跑步目标设置 | ✅ | ✅ |
| 个人跑步记录 | ✅ | ✅ |
| 班级累计 / 路线进度 | ✅（云端可用时） | ✅（云端可用时） |
| 排行榜 | ✅（云端可用时） | ✅（云端可用时） |
| 锁屏持续 GPS | ✅（Android 前台 Service） | ❌ iOS 限制 |
| App Store / TestFlight | — | ❌ 未交付 |
| 原生通知 | ✅ Android 通知 | ❌ 未交付 |
| 离线使用 | ✅ 本机缓存 | ✅ 本机缓存 |

## 关键边界

1. **iPhone 锁屏后 GPS 可能停止**——建议户外跑时保持屏幕常亮，或使用室内跑。
2. **云端功能依赖后端可用**——Supabase 后端恢复后，登录/统计/排行/路线进度才可用。
3. **两端共享账号体系**——同一邮箱账号可在 Android 和 iPhone 登录，数据云端一致。
