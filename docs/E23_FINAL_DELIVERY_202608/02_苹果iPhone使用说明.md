# 02 · 苹果 iPhone 使用说明

> **iPhone 当前交付形态：Safari / PWA（无需安装 App）**
> 原生 iOS App 与 TestFlight 尚未交付，请勿误认已完成。

## 1. 打开地址

用 **Safari 浏览器**打开（最新版 PWA，已部署）：

```
https://1e2a046fcb904f7dabc096741e391932.app.codebuddy.work
```

## 2. 添加到主屏幕

1. 在 Safari 打开页面
2. 点击底部 **分享** 按钮
3. 向下滑动，选择 **「添加到主屏幕」**
4. 确认名称 **E23跑起来** → 点击「添加」
5. 桌面出现图标，以后从桌面打开即可（全屏体验）

## 3. iPhone 已支持

- ✅ 打开 HTTPS 页面
- ✅ 登录 / 注册账号
- ✅ 查看个人跑步记录
- ✅ 查看班级累计与路线进度（云端可用时）
- ✅ 查看排行榜（云端可用时）
- ✅ 添加到主屏幕、从主屏幕打开
- ✅ 前台打开页面时使用定位功能（以实际验证为准）

## 4. iPhone 当前不承诺

- ❌ 锁屏后台持续 GPS 记录（iOS 限制）
- ❌ App Store 安装
- ❌ TestFlight 安装
- ❌ 原生 iOS 通知
- ❌ Core Location 原生后台定位

## 5. 正式表述

> iPhone 当前使用 PWA 内部体验版；后续原生 iOS 版本将采用 Capacitor iOS + Core Location。

## 6. 注意事项

- 建议 iPhone Safari 打开后「添加到主屏幕」使用，浏览器内体验更佳
- 户外跑定位仅在页面保持前台时工作；锁屏后可能停止记录
- 室内跑 / 手动补录在 iPhone 上完全可用
