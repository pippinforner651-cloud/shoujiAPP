# 05 · 开始跑步与结束保存说明

## 1. 进入跑步页

底部导航 → **「跑步」**

## 2. 选择模式

### 户外跑（推荐，使用 GPS）

1. 选择 **户外跑**
2. 点击 **开始户外跑**
3. 等待手机获取 GPS 信号（页面显示定位状态）
4. GPS 就绪后点击 **开始跑步**
5. 运动过程中可 **暂停 / 继续**
6. 结束后点击 **结束保存**

> GPS 获取较慢时，可参考「GPS 测试中心」诊断（我的 → GPS诊断）。

### 室内跑（跑步机/室内）

1. 选择 **室内跑**
2. 点击 **开始室内计时**
3. 运动结束后填写跑步机显示的真实距离
4. 保存

### 手动补录

跑步页底部 → **手动补录真实跑量** → 填写距离和时长 → 保存

## 3. 设置目标（可选）

跑步前可设置本次目标：

- **距离**：3 / 5 / 10 公里 / 半马 / 全马 / 自定义
- **时长**：20 / 30 / 45 / 60 分钟 / 自定义
- **热量**：100 / 200 / 300 / 500 千卡 / 自定义

> 目标仅本次有效，下次默认无目标；清除目标随时可操作。

## 4. 保存后

- 记录进入 **个人跑步记录**（云端 + 本机）
- 公里数计入 **个人累计** 与 **班级累计**
- 可在「我的」页面查看历史记录

## 5. 数据保存

- 户外跑：距离、时长、配速、GPS 轨迹
- 室内跑：距离（手动填写）、时长
- 手动补录：距离、时长

> 户外跑需获得精确定位权限；未授权时只能使用室内跑/手动补录。
