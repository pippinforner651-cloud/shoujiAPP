# 04 · 账号注册与登录说明

## 1. 注册账号

1. 打开 APP（Android）或 PWA 页面（iPhone）
2. 进入登录页 → 选择 **云端登录** 区域 → 点击「没有账号？去注册」
3. 填写：
   - 邮箱（建议使用常用邮箱）
   - 密码（至少 8 位，建议含字母+数字）
   - 昵称（同学们看到的名字）
4. 点击 **注册并加入**

> 注册后即为该账号创建独立的个人空间，跑步记录归属该账号。

## 2. 登录

1. 打开 APP / PWA
2. 输入注册时使用的 **邮箱 + 密码**
3. 点击 **登录**

## 3. 账号与数据

- 跑步记录保存在**云端**（登录状态下自动同步）
- 换手机 / 换平台（Android↔iPhone）登录**同一账号**，可恢复个人记录
- 每人只看到**自己的**跑步记录；班级累计为全体成员之和

## 4. 退出登录

「我的」页面底部 → 退出登录。
退出后本机不再显示个人记录；重新登录同一账号可恢复。

## 5. 注意事项

- 云端功能依赖后端服务可用；如提示网络错误，请稍后重试
- 内测期间账号无需审批，正式阶段可能增加班级审批流程
